# MESAPAGA Anti-Slop

Inspired by the open-source anti-slop project: https://github.com/miqdadbadjuber/anti-slop (MIT). This is a project-specific instruction skill, not a claim that the external plugin was installed.

## Non-negotiable baseline
- The official MESAPAGA public site is the source of visual truth. Do not redesign, rebrand, replace colors, remove parallax, or create a parallel website.
- Preserve the two existing demo entries: Probar restaurante and Probar cliente. A commercial presentation, if added, must be distinct.
- NFC-first. No client login or account. Use plain Spanish: Tu cuenta, Pagar toda la cuenta, Dividir entre personas, Elegir mis productos.
- Eliminate AI-sounding filler, invented testimonials, fake conversion percentages, fabricated payment claims, duplicate CTAs, decorative UI without purpose, and vague benefits.
- Keep the restaurant workflow to select table → HABILITAR PAGO; keep Dinii completion alert restaurant-only after authoritative full payment.
- Mobile-first readability, real tap targets, contrast, keyboard accessibility, reduced-motion support. Do not change visual identity to satisfy generic template preferences.
- Keep prices honest: Esencial 29 EUR no editable menu; Pro 69 EUR editable menu; Premium proposal only until approved.

## Review gate
Report PASS/FAIL for: official visual preservation; clarity and accuracy of copy; mobile/accessibility; no duplicate demos; no fabricated functionality. Include file references and screenshots/test evidence where available. If tests are unavailable say BLOCKED, never PASS. No financial authority.
